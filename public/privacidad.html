Privacidad

Política de privacidad

Esta política explica cómo EcuaVial utiliza la información necesaria para consultar el estado vial, mostrar reportes ciudadanos y ofrecer funciones de ubicación dentro de la aplicación.

Última actualización: 2 de septiembre de 2026

Información que puede recopilar la aplicación

  • Ubicación del dispositivo, únicamente cuando el usuario activa funciones como usar su ubicación, elegir un punto en el mapa o iniciar recorrido.
  • Nombre del reportante cuando se envía un reporte ciudadano.
  • Datos del reporte ciudadano: tipo de incidente, descripción, provincia, cantón, parroquia, coordenadas, vía detectada y fecha de creación.
  • Información técnica básica generada por servicios de alojamiento, analítica o funcionamiento web, como solicitudes, errores o datos de rendimiento.

Uso de la información

EcuaVial utiliza la información para mostrar incidentes viales en el mapa, ayudar al usuario a identificar su ubicación durante un recorrido, relacionar reportes con vías cercanas y mejorar la consulta ciudadana del estado vial.

La información no se vende ni se comparte con fines comerciales.

Ubicación y GPS

La ubicación se solicita solo cuando el usuario usa una función que la necesita. EcuaVial no rastrea permanentemente al usuario en segundo plano. El seguimiento de recorrido funciona mientras el usuario mantiene activa esa opción y permite el acceso a la ubicación desde el dispositivo.

Reportes ciudadanos

Los reportes enviados por usuarios son información ciudadana no verificada oficialmente. El usuario debe enviar datos responsables y verdaderos. EcuaVial puede mostrar estos reportes para apoyar la consulta vial, pero no reemplaza las indicaciones de autoridades competentes.

Servicios externos utilizados

  • Firebase Firestore, para almacenar reportes ciudadanos.
  • Vercel, para alojar la aplicación y sus servicios backend.
  • OpenStreetMap y Leaflet, para la visualización del mapa.
  • Servicios meteorológicos externos, para consultar el clima cuando la función está disponible.
  • Servicios de rutas como OSRM, para estimar recorridos cuando la aplicación lo requiere.

Conservación y eliminación

Los reportes ciudadanos pueden conservarse mientras sean útiles para la consulta vial y el mantenimiento del sistema. Si necesitas solicitar revisión o eliminación de información enviada, usa el formulario de bugs y sugerencias disponible en la aplicación.

Seguridad

EcuaVial utiliza servicios backend para evitar exponer credenciales sensibles en el navegador. Aun así, ningún sistema conectado a Internet puede garantizar seguridad absoluta, por lo que se aplican medidas razonables para proteger la información operativa de la aplicación.
